# Why Nuvsha?

Modern frontend development has become incredibly powerful, but also incredibly complex. 

Many frameworks require you to learn completely new paradigms:
- Complex state management hooks
- Dependency arrays that cause endless bugs
- Virtual DOM reconciliation rules
- Heavy component lifecycle methods
- Custom templating languages (like JSX) that break normal HTML

**Nuvsha exists to give you the power of reactivity with the simplicity of vanilla web development.**

## Less Code, More Results

With Nuvsha, you don't need to wrap your state in special functions (like `useState` or `ref`). You just declare a variable:

```javascript
count = 0
```

And when you change it, the UI updates:

```javascript
count = count + 1
```

It's that simple. The reactivity "just works."
