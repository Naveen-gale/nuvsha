# Forms Overview

Handling user input and form submission is notoriously difficult in modern web development. You often have to write boilerplate code to track `onChange` events, manage loading states, and handle errors.

Nuvsha drastically simplifies this with two powerful features:
1. **Two-Way Binding** (`bind={...}`): Instantly synchronize variables with input fields.
2. **Form Primitive** (`form({...})`): A built-in object that automatically manages form values, loading states, and submission lifecycles.
