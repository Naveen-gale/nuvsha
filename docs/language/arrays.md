# Arrays

You can store arrays in your variables and display their properties.

## Syntax

```html
<script>
  fruits = ["Apple", "Banana", "Cherry"]
</script>

<p>You have {fruits.length} fruits.</p>
<p>The first fruit is {fruits[0]}</p>
```

To render the elements of an array as HTML elements, you use [Loops](../logic/loops.md).
