# Objects

You can store complex objects in your variables and access their properties using dot notation.

## Syntax

```html
<script>
  user = {
    firstName: "Naveen",
    lastName: "G",
    role: "Admin"
  }
</script>

<h2>Profile</h2>
<p>First Name: {user.firstName}</p>
<p>Last Name: {user.lastName}</p>
<p>Role: {user.role}</p>
```
