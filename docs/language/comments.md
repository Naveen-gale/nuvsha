# Comments

You can use standard comments in both your script and template blocks.

## Syntax

```html
<script>
  // This is a single-line JavaScript comment
  
  /* 
     This is a multi-line 
     JavaScript comment 
  */
  score = 100
</script>

<!-- This is an HTML template comment. It will not be rendered to the user. -->
<p>Score: {score}</p>
```
