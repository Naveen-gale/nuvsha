# HTML

Nuvsha is designed so that valid HTML is always valid Nuvsha. You don't have to learn a completely new templating language like JSX.

## Syntax

```html
<div class="container">
  <header>
    <h1 class="text-2xl font-bold">My Website</h1>
  </header>
  
  <main>
    <p>Welcome to my normal HTML structure.</p>
  </main>
</div>
```

## What happens

The Nuvsha compiler parses standard HTML exactly as the browser would. You can copy HTML snippets from Tailwind UI or Bootstrap directly into your `.nuv` files and they will work seamlessly.
